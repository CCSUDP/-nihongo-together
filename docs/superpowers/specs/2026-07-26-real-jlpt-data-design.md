# 真实 JLPT 学习数据设计

## 目标

在现有“日语搭子”网站中接入覆盖 N5、N4、N3、N2、N1 的真实日语词汇和可答题的 JLPT 风格练习，并保存用户的答题结果与错题。

## 内容边界

- 词汇的日文词形、读音与词性以 JMdict 为主要参考。
- JLPT 等级映射采用开放社区数据，只标记为“参考等级”，不宣称为官方词表。
- 练习题由本站根据 JLPT 官方题型结构原创，不称为“历年真题”或“官方真题”。
- 官方样题仅提供来源链接和题型说明，不复制受限制的文章、题目和音频。
- 第一批每级至少 20 个高频词汇、5 道词汇或语法题，五个等级均可独立筛选和练习。

## 产品结构

1. `/vocabulary`：N5–N1 等级筛选、关键词搜索、日文词形、假名、中文释义、词性和数据来源。
2. `/practice`：选择等级后加载练习，逐题作答，即时显示结果与中文解析，完成后给出正确率。
3. `/sources`：说明 JMdict、开放 JLPT 等级映射、本站原创题目和官方样题链接。
4. 现有首页导航增加“词汇库”和“模拟练习”入口。

## 数据与身份

- 使用 D1 存储 `vocabulary`、`questions` 和 `attempts`。
- 只在服务端读取 D1，不把数据库绑定暴露给浏览器。
- 答题记录按平台转发的已认证用户邮箱归属；缺少身份时仍可答题，但不会写入个人记录。
- 查询接口只允许有限的等级、题型、分页大小和搜索长度。

## 交互与错误处理

- 词汇页首次进入默认 N5，可切换 N1–N5并搜索。
- 练习页默认 N5，每次从该等级题库读取一组题。
- 数据加载中显示骨架状态；失败时显示可重试提示；空结果显示清晰解释。
- 题目选定答案后才能提交；提交后锁定本题并展示解析。

## 验收

- 五个 JLPT 等级都有真实词汇和原创练习题。
- 词汇筛选、搜索、分页与练习作答可实际操作。
- 页面明确展示“参考等级”“JLPT 风格练习”和数据授权信息。
- D1 迁移包含表结构、索引和首批种子数据。
- 构建、渲染测试、接口检查与桌面端浏览器检查通过。
